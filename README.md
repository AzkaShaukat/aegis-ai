# Aegis AI  (ایجس اے آئی)   

A secure, multi-channel cybersecurity system for Pakistan that provides real-time threat detection for links, deepfakes, credentials, and QR codes through WhatsApp and Web interfaces.

## 🎯 Overview

Aegis AI serves as a powerful automated security assistant designed to protect non-technical users from sophisticated digital fraud. By utilizing a microservices architecture, it orchestrates deterministic heuristics, OSINT APIs, and local AI/ML models to deliver plain-English threat assessments without compromising user privacy.

## ✨ Key Features

- **Dual-Channel Access**: Accessible via a WhatsApp chatbot (Orchestra) and a React-based web dashboard.
- **Link Threat Analysis**: 11-layer deep evaluation of URLs utilizing heuristics, OSINT, and a Random Forest ML classifier.
- **QR Code Security**: Computer vision-based detection of physical tampering and robust deobfuscation of malicious payloads.
- **Credential Validation**: Breach-checking across 10+ formats (Passwords, CNICs, IBANs, API keys) with localized logic for Pakistani structures.
- **Profile Auditing**: ML-driven bot and impersonation detection for social media profiles.
- **Deepfake Detection**: PyTorch-based ensemble pipeline utilizing CNNs and Vision Transformers to detect manipulated media.
- **Explainable AI**: Natural language explanations generated by a local Ollama LLM for technical findings.

## 🏗️ Architecture

### Frontend (Client Layer)
- **WhatsApp Interface**: Handled via Meta WhatsApp Cloud API
- **Web App**: React 18+ with TypeScript, Vite, Tailwind CSS, and Zustand
- **Real-time**: Native WebSocket APIs for streaming chat responses

### Backend (Orchestration & Analyzers)
- **API Gateways**: `aegis-orchestra` (WhatsApp) and `aegis-web` (Web Backend)
- **Framework**: FastAPI with Python 3.11/3.12
- **Analyzers**: 5 independent stateless microservices (Link, QR, Credential, Profile, Deepfake)
- **Database**: PostgreSQL (Relational) and Redis (Cache, Sessions, Rate limits)
- **Local AI**: Ollama (Llama 3.2), PyTorch, scikit-learn

## 🚀 Getting Started

### Prerequisites
- Docker and Docker Compose
- Node.js 18+ (for frontend development)
- Python 3.11+
- Threat Intel API Keys (VirusTotal, URLScan, etc.)

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd aegis-ai
   ```

2. **Environment Setup**
   Copy the example environment files and configure your keys:
   ```bash
   cp .env.example .env
   # Configure your environment variables for each microservice
   ```

3. **Download AI Model Weights (Important)**
   Because the trained AI models are very large, they are not hosted on GitHub.
   - Place the downloaded `.pth` files directly into the `deepfake-api/app/models/` directory.

4. **Start the Infrastructure (Docker)**
   ```bash
   docker-compose up -d --build
   ```

5. **Database Migrations**
   ```bash
   docker-compose exec aegis-web alembic upgrade head
   ```

### Development

**Start the full development environment:**
```bash
docker-compose up
```

**Or run frontend separately:**
```bash
cd aegis-web/frontend
npm install
npm run dev
```

### Production Build (Frontend)

```bash
cd aegis-web/frontend
npm run build
npm run preview
```

## 🔐 Security Features

- **Privacy by Design**: Raw credentials are never stored. Only the first 16 characters of SHA-256 hashes are persisted.
- **k-Anonymity**: Passwords checked against HIBP by sending only the first 5 characters of the SHA-1 hash.
- **JWT Authentication**: Dual-token system with bcrypt password hashing for web users.
- **Webhook Verification**: HMAC-SHA256 signature matching for Meta's payloads.
- **Jailbreak Defense**: Prompt injection blocking for the LLM layer.

## 🌐 Supported Languages

- **English**: Primary technical and conversational language

- **Roman Urdu**: Supported conversational fallback

## 📊 Threat Coverage

- **Phishing & Smishing**: Comprehensive SMS/WhatsApp fraud detection explicitly tailored for local Pakistani scams (e.g., JazzCash, NADRA).
- **Identity Fraud**: CNIC format checks and impersonation detection.
- **Financial Scams**: IBAN, Credit Card, and Crypto wallet validation.
- **Malware & Botnets**: Integration with VirusTotal, URLhaus, and IPQS.
