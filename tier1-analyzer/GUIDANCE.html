Troubleshooting

ProblemSolution
Cannot connect to localhost:8003Docker containers not started. Run docker-compose up in the project folder.
Port 8003 already in useChange 8003:8003 in docker-compose.yml to 8004:8003 and update BASE in test file.
ModuleNotFoundError on startupCheck docker-compose.yml has NO volumes: block — that overrides the built image.
HIBP tests failing with "HIBP_API_KEY not configured"Add your key to .env then rebuild: docker-compose up --build
MX check slow (>5s)Normal — DNS resolution can be slow. Redis caches it after first call.
zxcvbn ImportErrorRebuild Docker: docker-compose build --no-cache
Redis shows "unavailable"System still works — Redis only caches external API calls. Check redis_t1 container started.

What Happens When You Scan an Email

Here is the exact sequence of operations when you POST to /analyze/email:

  1. Syntax check — validates RFC 5322 format, catches missing @, consecutive dots, etc.
  2. Normalization — strips Gmail dots, removes +tags, lowercases, NFKC Unicode normalize
  3. Homoglyph scan — checks every character against Cyrillic/Greek lookalike map
  4. Disposable check — looks domain up in the 600+ domain list (in-memory, instant)
  5. Async fan-out — the following 5 checks run concurrently at the same time:
    • MX DNS lookup — does this domain actually receive email?
    • HIBP API — breach history (cached 24h in Redis after first call)
    • psbdmp.ws — paste site search (cached 1h)
    • EmailRep.io — reputation score (cached 2h)
    • WHOIS — domain registration age (cached 24h)
  6. Score aggregation — all signals combined into 0–100 risk score
  7. Response returned — full JSON with every sub-result and flag list

Because steps 5a–5e run in parallel, the total response time is limited by the slowest external API — not the sum of all five.
